# SiamPlay — สยามเพลย์

SiamPlay V1.0 คือรากฐานเว็บไซต์รวม Mini Games ภาษาไทย

## จุดเด่น
- เล่นฟรี 100%
- ไม่ต้องสมัครสมาชิก
- Mobile First
- พร้อม Deploy บน Vercel
- V1.0 ยังไม่เพิ่มเกมจริง

## เทคโนโลยี
Next.js 14 + TypeScript + Tailwind CSS

## เริ่มต้น
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
